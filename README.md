# NavVerse · 趣导导航（PHP 版）

一个**零依赖**的网址导航站：PHP + SQLite，不需要 Node、不需要 Composer、不需要 MySQL，任何支持 PHP 7.4+ 的空间上传即用。前台是玻璃拟态深色风格，后台提供网址、分类、文章、页面、广告、聊天室、数据看板等完整管理功能。

---

## ✨ 功能一览

**前台**
- 顶部玻璃拟态导航，支持父页面 → 子页面下拉菜单
- 左侧分类浏览（主分类 + 无限层级子分类）、中间网址墙、无限滚动
- 右侧栏三种展示模式：图片 / 图文 / 纯文字，可后台切换
- 白天 / 黑夜主题 + 7 套渐变背景自选；自定义鼠标指针、背景音乐
- 悬浮聊天室、友情链接、文章页、聚合页、RSS、sitemap、404 页面
- 移动端自适应（两列 / 窄屏单列）

**后台**（`/admin/`）
- 网址管理、分类管理、文章管理、页面管理、内容编辑、广告位设计器
- 书签导入、导航采集、书签重复检测、死链扫描
- 网址 Logo：自动高清抓取、🖼 强制重抓、📤 上传图片、✂ 截取图片，以及带进度窗的「更新高清图标」「一键高清化」
- 网站图标 favicon 可在系统设置里直接上传替换（支持 ico / png / jpg / svg / webp）
- 系统设置（卡片拖动排序）、数据看板（折线 / 环形 / 条形图 + CSV）、访客记录
- 文件管理（上传、新建目录、拖拽上传、复制地址）、备份 / 恢复
- 左侧功能菜单支持「功能密码」解锁后显示

## 🧩 环境要求

| 项目 | 要求 |
| --- | --- |
| PHP | **7.4 及以上** |
| 必需扩展 | `pdo_sqlite` 或 `pdo_mysql`（二选一）、`json`、`session`、`mbstring` |
| 推荐扩展 | `gd`（Logo 高清化 / 截图 / WebP 转换）、`openssl`（授权验签）、`curl` 或 `allow_url_fopen`（抓取网站标题与 Logo） |
| Web 服务器 | Nginx 或 Apache，虚拟主机也可 |
| 其它 | 无需 Node、无需 Composer、无需独立 MySQL 服务 |

## 🚀 安装（3 步）

1. **上传**：把本仓库全部文件上传到站点根目录。
2. **安装向导**：浏览器打开 `http://你的域名/install.php`，按三步向导填写：
   - ① 环境检测（PHP 版本、数据库驱动、目录可写性，有红色 ✗ 会提示去面板里改哪里）
   - ② 站点与管理员（站点名称、标语、管理员账号 / 密码 / 邮箱）
   - ③ 数据库与展示（SQLite / MySQL、每页网址数量、是否安装示例数据）
   
   点「开始安装」后自动建库、写配置，完成后可直接进后台。
3. **收尾**：点页面上的「删除安装文件」按钮（或手动删除 `install.php`），然后访问 `http://你的域名/admin/` 登录后台。

> 老站点升级不会强制重装；已存在数据库且已有站点名称时会自动补安装标记。
> **忘记管理员密码**：删除数据库文件重新走安装向导即可（会清空全部数据，慎用）。

**数据库二选一**
- **SQLite（默认，推荐）**：零配置，库文件自动放在站点根目录**上一级**的 `_znavdata_xxxxxxxx/` 目录，公网无法通过 URL 下载；主机不允许写上级目录时可在向导里改选站点内 `data/nav.db`。
- **MySQL**：填库名 / 账号 / 密码 / 表前缀即可。

宝塔面板部署：软件商店装 Nginx + PHP 7.4+ → 添加站点 → 上传文件 → 打开 `/install.php`。

## 📁 目录结构

```
├── index.php / hub.php / article.php / rss.php / 404.php   # 前台页面
├── api.php                                                # 全部前后端接口

├── check.php                                              # 部署自检（查完删除）
├── admin/index.php                                        # 后台单页应用

├── lib/                                                   # db / seo / hub / compat / license / sub

├── config/license.local.php.example                       # 可选：本地授权配置模板

├── .htaccess                                              # Apache 规则（含 404、缓存）
├── .user.ini                                              # PHP 上传/执行限制示例
├── nginx-security.conf                                    # Nginx 安全规则示例
├── navverse-update.example.json                           # 源码更新公告 JSON 示例
```

## 🔐 部署后必做的安全设置

1. **立刻修改管理员密码**与「功能隐藏密码」（后台 → 系统设置），不要使用出厂默认值。
2. **删除 `install.php` 和 `check.php`**：前者可重建站点，后者会暴露服务器路径信息。
3. **禁止直接访问数据与库目录**：Apache 用仓库自带 `.htaccess`；Nginx 参考 `nginx-security.conf`（禁止 `/data/`、`/lib/`、`*.db`，并禁止 `uploads/` 下执行 PHP）。
4. **开启 HTTPS**，并限制 `uploads/` 目录的脚本执行权限。
5. **定期备份**：后台「系统设置 → 备份 / 恢复」，或定期复制数据库文件。
6. 若主机开启了 PHP `open_basedir`，请把站点根目录（以及库文件所在目录）加入允许列表，否则文件管理与 Logo 抓取会失败。

## 🧭 常用操作

- **改站点名称 / 标语 / 图标 / 主题**：系统设置，单列卡片可拖动排序。
- **换 favicon**：系统设置 → 网站图标，上传后自动加缓存戳，立即生效。
- **Logo 不理想**：网址管理行内 🖼 强制重抓、📤 上传高清原图、✂ 截取；工具栏「更新官网 Logo」「扫描死链」「查重复」。公开版对矢量 SVG 原样保存、栅格图绝不放大，避免低分辨率图被拉伸发虚。
- **首页分区数量**：系统设置里的 `homePerSection`，点「展开全部」再按需加载剩余网址。
- **更新提醒**：源码内置默认更新检查地址 `https://vvv.cu.ma/download/navverse-update.json`（一个返回 `version` / `download` / `changelog` 的 JSON），后台「系统设置 → 更新检查地址」可随时覆盖；也可参考 `navverse-update.example.json` 自建更新源。
- **改完代码没变化**：`Ctrl + F5` 强制刷新；Logo 图片带 `?v=` 缓存戳。

## ❓ 常见问题

**Q：后台接口报「HTTP 200，响应体为空」，文件管理显示空、新建文件夹失败？**
不是代码问题。通常是本机系统代理 / VPN / 浏览器代理插件，或站点前置的 CDN / WAF 拦截了 `POST /api.php`（页面 GET 能过、带自定义头的 POST 被吞）。把域名加入代理绕过（直连），或在防火墙放行 `/api.php` 的 POST；本地部署请直接用 `http://127.0.0.1/admin/`。

**Q：文件管理报 `scandir 返回 false … open_basedir=…`？**
PHP 的 `open_basedir` 限制了站点根目录，在主机面板的 PHP 设置里把站点根目录加入允许范围。

**Q：PHP 500 / 白屏？**
打开 `check.php` 看自检结果（版本、驱动、目录权限）；确认 PHP ≥ 7.4 且 `pdo_sqlite` 或 `pdo_mysql` 已启用。

**Q：Logo 抓成了 favicon 或社交分享图？**
部分站点把品牌标识放在内联 SVG / CSS 背景图里，程序会优先尝试站头主页链接容器中的真实品牌图；仍不理想时用行内 📤 上传或 ✂ 截取最可靠。

**Q：透明底 PNG 的 Logo 显示异常？**
前台 `.sc-logo` 保持透明背景，不要在样式里给它加白底。

## 📦 关于本公开版

本仓库是**开源自用版**。与内部完整版相比，**只有下面两类内容做了处理，其余源码一律原样保留、没有任何删减或占位化替换**。

### 一、不公布 / 已移除（仅此两类）

1. **NavVerse 授权管理的核心机密**：授权服务器地址（`ZNAV_LIC_SERVER`、`.lic_server_pref`）、RSA 公钥（`ZNAV_LIC_PUBKEY`）、授权体系诊断脚本 `_lic_diag.php`。授权模块的**代码与界面全部保留**（验签 / 激活码 / 离线授权 / 回检 / 吊销推送 / 授权卡片 UI 与文案），只是不内置地址与公钥，因此默认 `ZNAV_LIC_ENFORCE = false`、后台开箱即用不锁功能，也不会弹「授权服务器地址尚未配置」提示。
2. **后台 / 工具登录密码的明文默认值**：`submgr/index.php` 不再内置任何默认口令，改为读取环境变量 `SUBMGR_PASS` 或由部署者自行填写；未配置时登录与订阅导出接口直接拒绝，不会退化成弱口令。NavVerse 后台管理员密码由安装向导写入数据库，源码中本来就不存在。

### 二、完整保留（按「不能删减」要求）

- **源码更新检查地址** `ZNAV_UPDATE_URL` 按原值保留，后台不会出现「未配置更新检查地址」。
- **订阅 / 本地内核模块** `lib/sub.php` 原文件完整保留；**网页版订阅管理工具** `submgr/` 完整保留（仅移除明文默认口令）。
- 站点示例域名、本机路径示例、xray 相关文案、`sitemap.xml`、`_probe.php`、`.user.ini`、`README.txt`、`navverse-update.example.json` 等全部按原样发布。
- **作者联系方式**：QQ 号、微信号与微信二维码（`assets/contact_wechat.jpg`，以及内嵌在 `lib/db.php` / `assets/admin.js` 中的二维码图片）按作者要求原样保留；授权卡片的价格套餐与购买文案同样原样保留。
- 未发布的只有**运行数据**：`uploads/`（本地 1.4 万+ 个文件 / 238MB）、`data/` 运行内容、数据库文件——它们不是源码。

### 可选：启用商业授权

授权功能**没有被删除**，只是默认不启用、且不内置任何地址或密钥。要启用：

1. 复制 `config/license.local.php.example` 为 `config/license.local.php`（该文件已被 `.gitignore` 排除，不会提交、也不会泄露你的地址和公钥）；
2. 填入自己的授权服务器地址、RSA 公钥（`ZNAV_LIC_SERVER` / `ZNAV_LIC_PUBKEY`）；
3. 确认无误后把 `ZNAV_LIC_ENFORCE` 改为 `true`，授权门闸立即生效，未授权时后台按原设计锁定。

`lib/license.php` 会自动加载这个本地配置文件，无需修改公开源码；升级覆盖源码时配置也不会丢。源码里的 `ZNAV_UPDATE_URL` 已按原值保留，配置文件中不要重复定义它。
